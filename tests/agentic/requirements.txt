# Client libraries the agentic lane drives in-process, layered over the project
# environment by `uv run --with-requirements` (see tests/agentic/README.md).
#
# Deliberately kept out of pyproject.toml: uv.lock is a single universal resolution
# covering every dependency group at once, so a client declared there would be
# resolved against the gateway's own constraints and pinned to whatever satisfies
# them both. Every other tool in this lane floats -- the container images install
# unpinned packages so an upstream regression surfaces here -- and these clients
# float for the same reason. `--refresh` re-resolves them, mirroring what
# `--agentic-rebuild` does for the images.
#
# Nothing outside tests/agentic/ may import these: the rest of the suite runs
# without the overlay, and tests/agentic/conftest.py skips whichever modules are
# missing their client.
